# bloodwork.sh

[![skills.sh](https://skills.sh/b/bot-boyz/bloodwork.sh)](https://skills.sh/bot-boyz/bloodwork.sh)

A skill that lets an AI agent order cash-pay Quest and Labcorp blood tests through [bloodwork.sh](https://bloodwork.sh)'s
MCP server.

```sh
npx skills add bot-boyz/bloodwork.sh
```

| Skill                                    | What it does                                                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [`bloodwork`](skills/bloodwork/SKILL.md) | Finds the test, books a draw near the person, takes payment from the agent's wallet or by card, and reads results. |

The person always gives consent themselves.
